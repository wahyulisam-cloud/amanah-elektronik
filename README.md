# Amanah Elektronik

Sistem administrasi penyewaan perangkat elektronik berbasis web untuk membantu pengelolaan data alat, pelanggan, transaksi penyewaan, dan pengembalian.

## ✨ Fitur

- Login admin
- Dashboard
- Pengelolaan kategori
- Pengelolaan alat
- Pengelolaan pelanggan
- Pengelolaan penyewaan
- Pengembalian alat
- Laporan

## 🛠️ Teknologi

- React.js
- Laravel
- MySQL
- RESTful API
- JWT
- Postman

## 🖼️ Tampilan

Screenshot aplikasi akan ditambahkan pada bagian ini.
