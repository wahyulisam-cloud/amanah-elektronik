# Amanah Elektronik

## 📖 Tentang Project

Amanah Elektronik merupakan sistem administrasi penyewaan
perangkat elektronik berbasis web yang digunakan untuk
mengelola data alat, pelanggan, transaksi penyewaan,
dan pengembalian.

## ✨ Fitur

- Login admin
- Dashboard
- Pengelolaan kategori
- Pengelolaan alat
- Pengelolaan pelanggan
- Pengelolaan penyewaan
- Pengembalian alat
- Laporan

## 🛠️ Teknologi

- React.js
- Laravel
- MySQL
- RESTful API
- JWT
- Postman
